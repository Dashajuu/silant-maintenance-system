# Silant Maintenance System

**Silant Maintenance System** — это веб-приложение для управления техническим обслуживанием вилочных погрузчиков бренда «Силант» и их комплектующих. Приложение поддерживает работу с разными ролями пользователей (гость, клиент, сервисная организация, менеджер), обеспечивает контроль и отслеживание состояния техники, историю ТО, рекламации и коммуникацию между участниками.

Проект построен с использованием **Django**, **HTML**, **CSS**, **JavaScript** и **Django REST Framework**.

##  Features

- Регистрация и аутентификация пользователей с разными ролями (гость, клиент, сервисная компания, менеджер ЧЗСА): регистрация проходит через менеджера, пользователь самостоятельно зарегистрироваться не может
- Управление клиентами и их техникой (вилочные погрузчики, комплектующие)
- Инициация и отслеживание технического обслуживания (ТО)
- Управление сервисными организациями и мастерами
- Создание и обработка рекламаций (доступно сервисным компаниям и менеджерам)
- Ролевой доступ к функционалу и данным через группы и права
- API на базе Django REST Framework для взаимодействия с фронтендом
- Интуитивный интерфейс для мониторинга состояния техники и истории обслуживания

## Используемые технологии

- Backend: Python, Django, Django REST Framework
- Аутентификация и управление пользователями: Django auth, кастомные группы и права
- API: REST API с эндпоинтами для всех ключевых сущностей (клиенты, ТО, рекламации, сервисные компании)

## Установка и запуск

### Требования

- Python 3.8+
- pip

### Шаги

1. **Клонируйте репозиторий**:

   ```bash
   git clone https://github.com/Dashajuu/silant-maintenance-system.git
   
2. **Создайте виртуальное окружение и активируйте его**:

   ```bash
   python -m venv venv
   venv\Scripts\activate
  
4. **Установите зависимости**:

   ```bash
   pip install -r requirements.txt

5. **Примените миграции**:

   ```bash
   cd silant-maintenance-system/backend
   python manage.py migrate

6. **Запустите сервер**:

   ```bash
   python manage.py runserver

7. **Access the application**:

   Open your browser and navigate to http://127.0.0.1:8000/
